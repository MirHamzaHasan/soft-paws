# BarkLog Monetization Engagement

Read [../../../docs/agentic/product-truth.md](../../../docs/agentic/product-truth.md) and [references/growth-playbook.md](references/growth-playbook.md).

## Monetization Rules

- keep basic logging useful for free users
- gate leverage, insight, automation, or multi-dog coordination
- never degrade emergency trust with aggressive upsell behavior
- tie premium prompts to a real value moment, not arbitrary session timing

## Engagement Rules

- reward consistency with clarity and reassurance, not noisy gamification
- prefer helpful reminders and recap loops over streak pressure
- use Memory Book and progress narratives as shareable emotional moments

## Output Contract

Return:

- target user segment
- trigger moment
- free vs premium behavior
- success metric
- guardrails against spam or trust erosion
