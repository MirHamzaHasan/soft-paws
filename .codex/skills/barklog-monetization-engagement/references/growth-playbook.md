# BarkLog Growth Playbook

## Premium Value Areas

- AI weekly narratives and richer insight depth
- professional Vet Report export
- toxicity camera identification
- multi-dog management and household coordination

## Good Upgrade Moments

- after repeated logging shows clear commitment
- when the user tries to compare trends over time
- before generating a report or premium export
- when a household needs multi-dog support

## Avoid

- blocking a first-time log with an upsell
- inserting paywalls into emergency or first-aid surfaces
- hiding recent history behind premium
- using streaks that create guilt during stressful pet care moments

## Core Metrics

- activation to first logged event
- activation to second-day return
- free to premium conversion at value moment
- reminder opt-in rate
- weekly narrative open rate
- Memory Book share or save rate
