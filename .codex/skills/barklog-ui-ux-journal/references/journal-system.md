# BarkLog Journal System

## Visual Rules

- background: warm white, quiet, paper-like
- text: near-black, high contrast
- type: Inter, mostly 400 and 500
- decoration: minimal
- structure: thin borders and spacing, not shadows

## Home Screen Heuristics

- show the four primary log events immediately
- keep daily context visible
- make dog switching fast for multi-dog homes
- let users add nuance without blocking the one-tap path

## Insights Heuristics

- summarize trends in plain language
- separate facts from interpretation
- make weekly narratives scannable, not essay-like

## Emergency Heuristics

- use sober copy
- front-load contact and action steps
- never hide urgent guidance behind premium or clutter

## Archive Heuristics

- Memory Book can feel warm and reflective
- Vet Report should feel structured, factual, and printable
- Expense views should favor clarity over ornament
