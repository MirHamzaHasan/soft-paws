# BarkLog UI UX Journal

Read [../../../docs/agentic/product-truth.md](../../../docs/agentic/product-truth.md) and [references/journal-system.md](references/journal-system.md).

## Design Intent

Design BarkLog like a calm, precise caregiving journal. It should feel trustworthy, tactile, and direct instead of cheerful, medical, or gamified.

## Interaction Rules

- make the primary action obvious within one glance
- keep routine event logging tap-first
- move detail to long-press, secondary routes, or sheets
- use color for event category and status only
- use strong hierarchy instead of visual effects

## Output Contract

When designing a screen or flow, return:

- the user goal
- the content hierarchy
- the primary and secondary actions
- empty, error, and offline states
- accessibility notes
- implementation handoff notes for Tamagui
