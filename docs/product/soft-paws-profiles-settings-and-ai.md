# Soft Paws · profiles, settings and AI

22 October 2026. Task012 completes the remaining approved native destinations in
shared Compose. The same local controllers and native adapters own outcomes.

Profile details, independent saved cats and care notes remain local. Editing uses
the existing profile draft and captured revision, validates the updated facts and
returns only after the repository commits. Optional age, sex, stage, lifestyle,
neuter status, weight/unit, photo and saved contacts remain editable. Existing
cats can be selected freely. Additional creation requires the existing Premium
boundary and starts the complete independent setup; the intro alone creates no
cat and copies no consent/history. Final confirmation alone creates the profile.

Settings retain theme, reduced motion, contrast, Home shortcuts and optional soft
sounds. The new Larger text preference scales app text to 130% of the phone's
setting. It does not change the operating system. Notifications lead to the
existing per-task opt-in flow. Data choices expose free CSV, local photos,
separate account deletion and deliberate local deletion. Cancel is the first
choice and a second confirmation precedes destructive local changes. Unconfigured
account deletion is unavailable; deleting an account does not delete local care or
cancel a store subscription.

Soft Paws AI retains the compact conversation, working composer/history and actual
response controller. Intro, versioned current-cat consent, saved source excerpts
and an unavailable-service destination now share the cat kit. Consent covers the
current profile and past seven calendar days, excluding other cats, older records,
photos/documents and contacts. A source view shows the snapshot captured for its
answer; opening an original record verifies its current existence and cat identity.
Deleted originals retain their historical excerpt without pretending to be live.
The unavailable view keeps the question/draft and provides free saved contacts;
returning does not send or retry. Design-fixture answers are explicitly demos.
Fresh identity, Premium, real configuration and Release server gates remain in
place. No live request, service registration, model download or upload is added.

Empty and loading states reflect actual repository startup/record counts. Failed
saves retain real fields and drafts, and success follows a committed retry.
Revision conflicts preserve the edit and offer the actual newer record. Photo
permission denial never blocks care logging. Missing private files retain their
caption/date/reference and offer replacement; no substitute image is invented.
The offline guide links to usable local care and saved contacts.

Original Rive cat art/runtime, transparent interaction, bounded reactions and
reduced-motion stills remain shared with the rest of Soft Paws. Both themes retain
the approved joyful palette and Bricolage/Inter typography. Native implementation
and individual visual approval are tracked separately in the parity inventory.

verification and remaining release gates.
