# Owned native review fixtures

`qa-park-day-v1.jpg` is the board’s original code-drawn example landscape, captured from `.bl-photo-scene` on `photo-detail`. It is a synthetic QA image, never a caregiver photo. Install it only on owned BarkLog Exact Board QA devices, under the corresponding private photo directory. The `park-full-v1` database references it; `qa-missing-v1.jpg` is deliberately absent.

All review datasets have their own SQLite filename and preference namespace. They never reset a normal journal. The fixed clock is 14 October 2026 at 18:24 UTC. Replay never reseeds records.
