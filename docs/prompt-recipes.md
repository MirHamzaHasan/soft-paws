# Continuing the rebuild

Start one vertical slice at a time using [the task index](../tasks/README.md).

Example: "Implement task002 with local SQLDelight storage on Android and iOS.
Follow the canonical spec and verify failure, migration and restart behavior."

Example: "Implement task003: dog setup, Home quick logging and a local Timeline.
Use the real repository, show success only after commit, and test both hosts."

Example: "Review task007's reminder behavior on iPhone when permission is denied.
Record failures and actual verification; do not mark device QA complete from a build."

For each prompt provide the task/screen, desired behavior and acceptance changes.
Credentials are never a prerequisite for local journal implementation.
